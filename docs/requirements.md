# Требования к FlowBoard

## Назначение

FlowBoard помогает одному пользователю планировать учебные и личные задачи по канбан-методу. Граница первой версии: одна личная доска на аккаунт без совместного доступа.

## Роли

| Роль | Права |
|---|---|
| Гость | Открыть страницу, зарегистрироваться, войти, проверить health endpoint |
| Пользователь | Управлять только своими задачами, смотреть свою статистику и журнал |
| Администратор БД | Применять миграции, проверять целостность, создавать и восстанавливать backup через CLI |

## Функциональные требования

| ID | Требование | Критерий приёмки |
|---|---|---|
| FR-01 | Регистрация | Валидные имя, email и пароль создают аккаунт и сессию; дубль email отклоняется |
| FR-02 | Вход и выход | Верные данные создают сессию; выход очищает cookie |
| FR-03 | Создание задачи | Название обязательно; описание, статус, приоритет и срок опциональны |
| FR-04 | Изменение задачи | Изменения сохраняются атомарно; устаревшая версия отклоняется |
| FR-05 | Перемещение | Карточка переходит в `backlog`, `in_progress` или `done` через drag-and-drop и кнопки |
| FR-06 | Удаление | После подтверждения карточка исчезает; событие остаётся в журнале |
| FR-07 | Поиск и фильтр | Поиск работает по названию и описанию; фильтр — по приоритету |
| FR-08 | Статистика | Интерфейс показывает общее число, работу, готовые и просроченные |
| FR-09 | Журнал | Последние 10 действий отображаются в обратном порядке |
| FR-10 | Администрирование | CLI применяет миграции, проверяет БД, создаёт и восстанавливает backup |

## Нефункциональные требования

- NFR-01. Проект запускается на Python 3.12 без внешних библиотек.
- NFR-02. Основные экраны адаптивны для ширины от 320 px.
- NFR-03. Все API-ответы имеют JSON-формат; контракт описан в OpenAPI 3.0.
- NFR-04. Пароли не хранятся в открытом виде; сессии и CSRF-токены криптографически подписаны.
- NFR-05. Все изменения БД выполняются в транзакциях; включены foreign keys и WAL.
- NFR-06. Критическая логика покрыта модульными и HTTP-тестами; CI запускает их для каждого push и pull request.
- NFR-07. Код не содержит производственных секретов; они передаются через environment.

## Модули и интерфейсы

| Модуль | Ответственность | Интеграция |
|---|---|---|
| `public/app.js` | UI-состояние, формы, drag-and-drop, Fetch | JSON/HTTP с `kanban.web` |
| `kanban.web` | Маршрутизация, cookie, CSRF, security headers | Вызывает `BoardService` |
| `kanban.service` | Валидация и бизнес-правила | Транзакции через `Database` |
| `kanban.database` | Соединения, migrations, seed, integrity check | SQLite 3 |
| `kanban.security` | scrypt/PBKDF2, HMAC-сессии, CSRF, валидация | Стандартная криптография Python |
| `scripts/db_admin.py` | Миграции, мониторинг, backup/restore | SQLite backup API |
