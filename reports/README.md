# Отчеты по производственной практике

- `Отчет_ПМ02_FlowBoard.docx` — ПМ.02 «Осуществление интеграции программных модулей».
- `Отчет_ПМ11_FlowBoard.docx` — ПМ.11 «Разработка, администрирование и защита баз данных».

Документы собраны на основе шаблонов колледжа. Технические разделы заполнены по фактически реализованному проекту FlowBoard. Поля ФИО, курса, группы, оценок и подписей оставлены пустыми, так как этих данных не было в исходных материалах.

## Перед сдачей

1. Заполнить персональные поля, получить подписи и оценки руководителя.
2. Создать публичный экземпляр через кнопку **Deploy to Render** в корневом README и вставить его URL в технический паспорт отчета, если нужен уровень «5».
3. При необходимости уровня «4/5» зарегистрировать репозиторий в Code Climate и добавить реальный бейдж A/B; в текущем отчете честно указано, что сервис не подключен.
4. Убедиться, что ссылки открываются в режиме инкогнито, а тестовый вход `demo@example.com / Demo123!` работает.

Пересборка отчетов:

```bash
python3 scripts/build_reports.py
```

Зависимости для пересборки устанавливаются командой `python3 -m pip install -r requirements-dev.txt`; само приложение FlowBoard внешних Python-зависимостей не использует.
